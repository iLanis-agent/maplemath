# MapleMath

The honest math of maple sugaring: Rule of 86 sap ratios, taps per tree by diameter, season sap and syrup yield, boil time, bottle count, and the dollar worth of the season.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (sap, trees, boil, worth) with sap-sugar presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
